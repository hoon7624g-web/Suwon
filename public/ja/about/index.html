このサイトについて

水原閣は、水原の旅行情報サイト「수원각」のこの言語版です。観光地・飲食店・宿泊施設について、営業時間、料金、駐車場、行き方をまとめています。旅行コースと祭りの日程も載せています。

掲載内容

この言語のページは、場所400か所、ガイド6本、コース6本、祭り・イベント18シリーズです。場所のうち400か所は検索結果に表示されます。残りは一覧には載せていますが、サイトの索引基準を満たすまで検索エンジンには登録しません。

日本語の各ページは、韓国語ページの翻訳です。韓国語ページが変わると、翻訳を更新するまで翻訳ページを取り下げます。そのため、両者の内容が食い違うことはありません。

ページの作り方

営業時間、休業日、料金、駐車場、電話番号、チェックイン時間、メニューは韓国観光公社のTourAPIから得ています。一部の場所は、その場所の公式ウェブサイトからも得ています。一般的な知識で補った値はありません。

すべての値に出典を示します。二つの情報源で値が異なる場合は、両方をそれぞれの出典とともに示し、「情報源によって値が異なります。訪問前に電話でご確認ください」と記します。どの情報源にもない値は、「記載なし」と一度だけ記します。

利用条件（公共ヌリ類型）が確認されていない原文は転載しません。ページから原文へリンクし、説明文は新たに書き起こし、営業時間・料金・メニューなどの事実値は出典どおり記載します。距離は座標間の直線距離で、移動距離ではありません。

このサイトは予約や支払いを受け付けません。スポット・ガイド・コースのページの「予約する」ボタンは、データにある公式の予約ページ（施設や公的機関が運営するもの）だけにつながり、旅行会社や宿泊予約アプリのリンクはボタンにしません。

写真

写真は、韓国観光公社が公共ヌリ（KOGL）で提供しているものです。公共ヌリ第1類型が191枚、公共ヌリ第3類型（変更禁止）が258枚です。第3類型の写真は公開されたとおりに掲載し、切り抜き・拡大・編集はしません。各写真に出典とライセンスを表示しています。

このサイトのイラストは生成AIで描きました。場所の写真はすべて韓国観光公社の公式写真で、出典とともに掲載しています。

名称

場所の名称は、韓国観光公社がこの言語の公式名称を示している場合はそれを使います。ない場合は韓国語の名称から訳しています（固有の部分は音写し、一般的な部分は翻訳）。各場所のページには韓国語の名称も載せています。韓国の地図で検索するときや、タクシーの運転手に見せるときに役立ちます。

緊急連絡先

人が倒れた・けがをした、火事や犯罪にあったときは、すぐに電話してください。

  • 119消防・救急車
  • 112警察
  • 1330観光案内・通訳（電話・チャット） · 海外から +82-2-1330

韓国語が話せない場合は、電話がつながったら 'English please' または 'Interpreter please' と伝えると、通訳につないでもらえます。

いる場所は、近くの建物の名前やスマートフォンが示す位置（GPS）で伝えてください。

出典：韓国観光公社（VisitKorea）（外国人旅行者向けの安全情報, 1330 観光通訳案内、英語）。このサイトは応急処置や医療の案内はしていません。

Site assistant

The ‘Ask’ button at the bottom right opens an assistant that answers only from this site's information: the values and sources on its place, guide, course and event pages, with a link to each page it uses. Where two sources differ it gives both; where the site has no value it says so and points to the phone number or official website in the data.

Answers are written by Claude Haiku 5.5, an AI model by Anthropic. AI answers can be wrong: check the linked pages and the official sources before you go. It cannot book, pay or sign you up; it only links to official booking pages.

This site does not store conversations on its server. The conversation stays only in this browser tab and is cleared when you press ‘New chat’ or close the tab. Each time you ask, the new question, the conversation before it (the last 12 messages) and the address of the page you are on go through this site's server function to the Anthropic API, which writes the answer. The server log keeps only the outcome and usage numbers, never your questions or the answers. What happens to them at Anthropic follows Anthropic's policies, and this site cannot delete what has already been sent.

Please do not type personal details such as names or phone numbers: nothing masks them automatically. If you typed one by mistake, press ‘New chat’; otherwise it is sent again with the conversation the next time you ask.
