# Site catalog of 수원각 (https://suwon.webforai.kr). One line = one page of this site.
# Line letter: P place, G guide, C course, E event series, V video topic page, T theme list, S site page. The second field is the page path: pass it to get_pages as is, and link the page as https://suwon.webforai.kr + path. A name in brackets is the place's English name (attractions and official English names; any other place's English name is its Korean name romanized, and its page has it); '다른 이름' = other names of the same place; '연중무휴' alone = open all year.
# A place line is short: name, type, 구·군 (the district of its address) and only these first-screen facts — 관광지: 휴무, 요금; 음식점: 메뉴, 휴무; 숙소: 없음 (휴무 = closed days, 요금 = admission fee, 메뉴 = signature dishes). A fact missing from a line is not evidence that the site lacks it: hours, parking, phone, check-in, the full fee table and the sources are in the place's page (get_pages). '외' = the page has more. '두 출처 다름' = two sources give different values and the page shows both (방문 전 전화 확인). 지정 = official designations the page lists.
# The full lines of the places this question most likely needs come in the site_data block whose source is "lines", given after this catalog, one per place: P path | name | type | where (읍·면·동 and travel area) | the place's summary sentence | every first-screen key fact as the page shows it — 관광지: 시간 (hours), 휴무, 요금, 주차 (parking), 전화 (phone); 음식점: 시간, 휴무, 메뉴, 주차, 전화; 숙소: 체크인, 체크아웃, 주차, 객실 (rooms), 전화 — | 지정. One of these key facts missing from a full line = the site has no value for it. A place without a full line in that block: read its page (get_pages) before you state any fact it does not show here.
