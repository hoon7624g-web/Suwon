Об этом сайте

Сувонгак — версия на этом языке сайта туристической информации о регионе Сувон «수원각»: часы работы, цены, парковка и схема проезда для достопримечательностей, ресторанов и жилья, а также маршруты и даты фестивалей.

Что здесь есть

Страницы на этом языке: мест — 400 (в результатах поиска — 400; остальные есть в списках, но не индексируются, пока не отвечают правилу индексации сайта), путеводителей — 5, маршрутов — 6, серий фестивалей и событий — 18.

Каждая страница на этом языке — перевод корейской страницы. Когда корейская страница меняется, переведённая страница снимается до обновления перевода, поэтому они никогда не расходятся.

Как создаются страницы

Часы работы, выходные дни, цены, парковка, телефоны, время заезда и меню взяты из TourAPI Национальной организации туризма Кореи, а для некоторых мест — с их официальных сайтов. Ничего не дополняется из общих знаний.

У каждого значения указан источник. Если два источника дают разные значения, на странице показаны оба, каждое со своим источником, и написано: «Источники расходятся — позвоните перед визитом.». Значение, которого нет ни в одном источнике, один раз отмечено как «Не указано».

Исходные тексты, условия использования которых (тип KOGL) не подтверждены, не копируются: страницы ссылаются на оригинал, описания пишутся заново, а часы работы, цены и меню сохраняются как в источнике. Расстояния даны по прямой между координатами, а не по дорогам.

Этот сайт не принимает бронирования и оплату. Кнопки «Забронировать» на страницах мест, путеводителей и маршрутов открывают только официальные страницы бронирования из наших данных (их ведёт само заведение или государственная организация); ссылки турагентств и приложений бронирования никогда не становятся кнопками.

Фото

Фотографии предоставлены Корейской организацией по туризму по лицензии Korea Open Government License (KOGL): 191 — по KOGL, тип 1, 258 — по KOGL, тип 3 (без изменений). Фотографии типа 3 показаны точно в опубликованном виде: без обрезки, увеличения и обработки. У каждой фотографии указаны источник и лицензия.

Иллюстрации на этом сайте нарисованы с помощью генеративного ИИ; каждая фотография места — официальная фотография Корейской организации по туризму с указанием источника.

Названия

Названия мест — официальные названия Национальной организации туризма Кореи на этом языке, если они есть; иначе названия переведены с корейского (собственная часть транскрибирована, родовая — переведена). На каждой странице места есть и корейское название: оно поможет при поиске на корейской карте или если показать его таксисту.

Site assistant

The ‘Ask’ button at the bottom right opens an assistant that answers only from this site's information: the values and sources on its place, guide, course and event pages, with a link to each page it uses. Where two sources differ it gives both; where the site has no value it says so and points to the phone number or official website in the data.

Answers are written by Claude Haiku 5.5, an AI model by Anthropic. AI answers can be wrong: check the linked pages and the official sources before you go. It cannot book, pay or sign you up; it only links to official booking pages.

This site does not store conversations on its server. The conversation stays only in this browser tab and is cleared when you press ‘New chat’ or close the tab. Each time you ask, the new question, the conversation before it (the last 12 messages) and the address of the page you are on go through this site's server function to the Anthropic API, which writes the answer. The server log keeps only the outcome and usage numbers, never your questions or the answers. What happens to them at Anthropic follows Anthropic's policies, and this site cannot delete what has already been sent.

Please do not type personal details such as names or phone numbers: nothing masks them automatically. If you typed one by mistake, press ‘New chat’; otherwise it is sent again with the conversation the next time you ask.
