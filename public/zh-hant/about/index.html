關於本站

水原閣是水原旅遊資訊網站「수원각」的本語言版本。本站彙整景點、餐廳和住宿的開放時間、費用、停車與交通方式，並附有旅遊路線與慶典日期。

本站內容

本語言共有681處地點頁面、5篇指南、6條路線及18個慶典系列。其中680處地點收錄於搜尋結果，其餘在滿足索引標準前暫不收錄。

本語言的每個頁面都譯自對應的韓文頁面。韓文頁面更新時，譯文頁面會先下架，待翻譯更新後再上線，因此兩者內容不會不一致。

頁面製作方式

營業時間、休息日、費用、停車、電話號碼、入住時間及菜單均來自韓國觀光公社的TourAPI，部分地點亦來自其官方網站。沒有任何內容憑常識臆測補充。

每個數值都標明來源。兩個來源數值不同時，頁面會同時列出兩者並各附來源，並註明「不同來源的資訊不一致，請出發前致電確認」。沒有任何來源提供的數值，只會標示一次「未提供」。

未確認使用條件（公共Nuri類型）的原文不予轉載：頁面提供原文連結，說明文字重新撰寫，營業時間、費用、菜單等事實數值保持來源原樣。距離為座標間的直線距離，而非實際通行距離。

本網站不接受預訂或付款。景點、指南和路線頁面上的「預訂」按鈕只連結到資料中的官方預訂頁面（由設施或公共機構營運），旅行社和住宿預訂應用程式的連結不會做成按鈕。

照片

照片來自韓國觀光公社，依韓國公共授權（KOGL）使用：193張為韓國公共授權（KOGL）第1類，537張為韓國公共授權（KOGL）第3類（禁止變更）。第3類照片依原樣呈現，不裁切、不放大、不修改。每張照片都標示來源與授權。

本站的插圖以生成式 AI 繪製；每張地點照片都是韓國觀光公社的官方照片，並標示來源。

名稱

地點名稱在韓國觀光公社提供本語言官方名稱時直接採用；否則由韓語名稱翻譯而來（專名部分音譯，通名部分意譯）。每個地點頁面同時標示韓語名稱，方便在韓國地圖中搜尋或出示給計程車司機。

緊急聯絡電話

有人昏倒或受傷、發生火災或遇到犯罪時，請立即撥打電話。

  • 119消防·救護車
  • 112警察
  • 1330旅遊諮詢·翻譯（電話·聊天） · 從海外撥打 +82-2-1330

不會說韓語時，電話接通後說 'English please' 或 'Interpreter please'，會為您轉接翻譯。

請用附近建築物的名稱或手機顯示的位置（GPS）告知您所在的地方。

來源：韓國觀光公社（VisitKorea）（給外國旅客的安全資訊, 1330 旅遊翻譯諮詢，英文）。本站不提供急救或醫療建議。

Site assistant

The ‘Ask’ button at the bottom right opens an assistant that answers only from this site's information: the values and sources on its place, guide, course and event pages, with a link to each page it uses. Where two sources differ it gives both; where the site has no value it says so and points to the phone number or official website in the data.

Answers are written by Claude Haiku 5.5, an AI model by Anthropic. AI answers can be wrong: check the linked pages and the official sources before you go. It cannot book, pay or sign you up; it only links to official booking pages.

This site does not store conversations on its server. The conversation stays only in this browser tab and is cleared when you press ‘New chat’ or close the tab. Each time you ask, the new question, the conversation before it (the last 12 messages) and the address of the page you are on go through this site's server function to the Anthropic API, which writes the answer. The server log keeps only the outcome and usage numbers, never your questions or the answers. What happens to them at Anthropic follows Anthropic's policies, and this site cannot delete what has already been sent.

Please do not type personal details such as names or phone numbers: nothing masks them automatically. If you typed one by mistake, press ‘New chat’; otherwise it is sent again with the conversation the next time you ask.
